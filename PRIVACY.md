# ShipBrief privacy policy

Last updated: 2026-11-25

ShipBrief is a Forge app that runs entirely on Atlassian's platform.

- ShipBrief reads Jira work items, comments, links, Confluence search results (judging edition only) and Teamwork Graph data only when a user opens the panel, asks the Rovo agent, or calls an MCP tool. Every request runs with that user's own permissions.
- ShipBrief does not store any data. It has no database, no app storage and no external server.
- ShipBrief does not send any data outside Atlassian. It makes no external network requests.
- ShipBrief writes to your site only when a user asks it to post a brief as a comment on a work item.
- Diagnostic logs kept by the Forge platform contain error messages and field names, not field values.
- The ShipBrief Rovo agent is run by Atlassian Rovo; Atlassian's own privacy policy applies to Rovo.

Uninstalling the app removes it completely; there is no data to delete.
